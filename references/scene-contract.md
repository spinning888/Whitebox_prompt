# Optional authoring record

Keep this record outside copy-ready prose when reproducibility or audit is requested.
It is a model-neutral evidence ledger, not an API request or mandatory schema.

Record only fields relevant to the supplied material:

- Source ID, file path, inspected coverage, duration, frame rate and actual cut times.
- Stable subject and prop IDs; proxy-to-role and appearance-image-to-role mappings.
- Each asset's function, inherited attributes and excluded attributes.
- Observed structure, supplied target design and unspecified completion as separate
  categories; record unresolved conflicts and confidence.
- Clip-level initial situation, supported event/reaction and endpoint.
- Key props: supported category, identifying appearance, initial holder/location,
  visible transfers and final state. Do not invent off-screen state transitions.
- Per-shot visible events, camera, continuity and evidence-supported timings.
- Environment inventory and shared finish policy, including background-only views.
- Audio analysis status and any explicit sound/music target.
- Supplemental source location/URL, claims used and permitted construction access.
- Frozen prompt version, language, input condition and any compilation/correction history.
- Output status (`complete_storyboard` / `evidence_limited` / `analysis_not_run`)
  and separate release status (`pending_review` / `frozen`), reviewer and unresolved items.
- Common cross-level timeline: shot/phase intervals, source frame or time evidence,
  precision, initial spatial state, action/response/contact where visible, camera
  behaviour, final state/hold and cut continuity. Unsupported fields stay unknown.
- For claims beyond direct observation, the supporting facts and interpretation;
  keep these separate from authored target choices and permitted free completion.
- Visual-target policy ID and acceptance class; broad unspecified finish alone is
  insufficient for proxy-leakage evaluation.

For example, a proxy handover alone supports “flat rectangular object changes from
A to B.” A released brief may identify it as a document folder for review. Record
the folder identity and purpose as brief-derived, keep the handover video-derived,
and do not add opening or reading. If the proxy geometry conflicts with the confirmed
prop, record that tension instead of claiming the prompt guarantees a visual fix.

Use paths, ordered IDs and direct comparisons when hashing is not permitted. This
record supports provenance; it does not establish that a generator followed inputs.
