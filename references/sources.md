# Scope and reference inspiration

The six-section structure is the user's local authoring convention. It is not an
official conference format and does not certify benchmark fairness.

The user supplied [a reference prompt specification](https://github.com/alchaincyf/seedance-skill/blob/main/references/prompt-spec.md)
as reading material. The transferable ideas are functional grouping of references,
attribute-scoped inheritance, clear scene content and temporal continuity. Provider
tokens, input limits, API fields and model-specific recipes are not part of this skill.

Scene-specific evidence and plot sources belong in each sample's authoring record,
not in universal instructions. External enrichment requires permission from the user
or the declared data protocol; it is never automatic proof of whitebox understanding.
